# Light & Dark Theme Toggle - React Native

A React Native app that implements dynamic Light and Dark theme switching.

### Features
- Toggle between Light and Dark mode on button press
- Fixed UI bugs and flickering issues on theme change
- Persistent theme state across the app
- Clean and responsive UI for both themes

### Tech Stack
- React Native, JavaScript
- React Hooks (useState / Context API)

### How to Run
1. npm install
2. npm run android / npm run ios
